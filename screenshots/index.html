【自制开源】给公交出行做了一款纯粹、优雅的实时到站追踪器 —— Trackr (BusOnRoad) 每次出门等公交，官方 App 广告多、臃肿卡顿？ 我花时间用 Jetpack Compose 和最新的 Material Design 3 Expressive 规范，重新做了一款干净、直观的实时公交追踪应用。 ✨ 核心亮点： 1. 【颜值即正义】完整遵循 Material 3 Expressive 规范，动态取色、悬浮胶囊工具栏、平滑弹簧动效，支持深浅模式。 2. 【竖向时间轴走向】沿站序从上往下排，候车站、途经车辆和已过站一眼看清。 3. 【实时车队雷达】一眼看清整条线路上所有在途车辆，车牌号、车速、舒适拥挤度、剩余站数全掌握。 4. 【常驻追踪】首页追踪卡片和通知栏常驻显示下一班，到站前自动提醒，不用反复掏手机刷新。 5. 【纯粹无广告】代码开源，无开屏广告、无无意义推送，只做纯粹的交通工具。 欢迎尝鲜体验与提出建议，项目已在 GitHub 开源！
[分享] 用 Jetpack Compose + Navigation 3 写了一款 Material 3 Expressive 风格的实时公交追踪器 Trackr 各位 V 友，平时通勤坐公交，市面上主流实时公交 App 的广告和信息流越来越重，经常只是想看下一班车还有几分钟，却被开屏卡顿折磨。 于是我写了 Trackr (BusOnRoad)，目标是做一款极简、高响应、体验现代的通勤利器。 🛠 技术栈细节： - UI：Compose Multiplatform，页面写在 commonMain，Material 3 Expressive 规范 - 导航：AndroidX Navigation 3，类型安全页面键、每个页签独立返回栈 - 架构：MAD 分层 + 单向数据流，ViewModel 暴露 StateFlow，页面无状态 - 依赖注入：Koin；网络：Ktor；存储：Room + DataStore - 测试：JUnit + Robolectric，全部在 JVM 上跑，不需要真机 开源地址：https://github.com/5151561/Trackr- 欢迎 PR、Issue 和 Star！
通勤党狂喜！终于挖到神仙颜值的实时公交 App 了 🚌✨ 真的受够了传统公交 App 满屏广告和劣质排版！ 被安利的这个宝藏 App「Trackr」，不仅零广告极简，而且界面完全是原生 Material Design 3 风格，美到像系统自带的一样！ 🌟 超戳我的几个细节： 1. 线路走向是竖向时间轴，从候车站往终点排，像地铁图一样清楚！ 2. 哪辆车到了哪一站、车牌、车速、还有几分钟到，全都写在站名旁边。 3. 置顶常驻追踪卡片，车快到站时会自动提醒，再也不用在大风里一直傻傻盯着路口张望了！ 4. 夜间模式质感绝了，通勤幸福感直线拉满～ #宝藏App #Android玩机 #手机桌面 #通勤必备 #实用工具 #UI设计
